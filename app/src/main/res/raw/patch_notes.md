**Last Played Tile**
- Games launched directly from ES-DE now show up in the Last Played tile with their scraped artwork and real title
- No more escaped filenames like `New\Super\Mario\ Bros`, the actual game name is used

**Canvas**
- New settings shortcut on tile options dialogs, tap the gear to jump straight to Settings
- Renamed "widget" labels to "tile" across Canvas text so terminology matches what you're actually placing

**Frontend**
- New Nintendo Switch 2 platform, games launch straight into Banana Native
- Switch 2 games can be added as .nup files, game dump folders (no renaming needed), or .titleid files for games already set up in Banana Native
- Games can now have up to two companion apps, and you pick which one to open at launch
